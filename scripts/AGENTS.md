# Scripts agent guide

This folder contains helper scripts to start and stop the local Dockerized app.

## Scripts

- Linux:
	- `start-linux.sh`
	- `stop-linux.sh`
- macOS:
	- `start-mac.sh`
	- `stop-mac.sh`
- Windows:
	- `start-windows.cmd`
	- `stop-windows.cmd`

All scripts run Docker Compose commands from the project root.
